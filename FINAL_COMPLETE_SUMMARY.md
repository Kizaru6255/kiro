## Usage Examples

### Registry Workflow
```bash
# Initialize registry
kiro registry init

# Search modules
kiro registry search payment

# Install module
kiro registry install payment-gateway

# Add to project
kiro add module payment-gateway
```

### Blueprint Workflow
```bash
# Create e-commerce app
kiro create app --blueprint ecommerce --name MyShop

# Creates app with:
# - Authentication
# - Payments
# - Profile
# - Notifications
# - Pre-configured theme
```

### Explain Workflow
```bash
# Understand module
kiro explain module auth

# Learn architecture
kiro explain architecture

# See dependencies
kiro explain dependencies
```
