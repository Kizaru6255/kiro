## Complete Command Reference

### App Creation
```bash
# Standard app
kiro create app

# With blueprint
kiro create app --blueprint ecommerce

# Sample app
kiro create app --sample
```

### Module Management
```bash
# Add module
kiro add module auth

# Remove module
kiro remove module auth

# Update module
kiro update module auth
```

### Registry Operations
```bash
# Initialize
kiro registry init

# Search
kiro registry search auth

# Install
kiro registry install auth

# List
kiro registry list
```

### Code Understanding
```bash
# Explain module
kiro explain module auth

# Explain architecture
kiro explain architecture

# Show dependencies
kiro explain dependencies
```

### Health Checks
```bash
# Basic check
kiro doctor

# Architecture check
kiro doctor --architecture

# Version check
kiro doctor --versions
```
